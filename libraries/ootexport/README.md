# OoT converter

A C17 exporter for the Ocarina of Time audio engine in a [zeldaret/oot](https://github.com/zeldaret/oot) checkout. It takes resolved MIDI events and produces a sequence in the decomp's `aseq.h` assembly, a soundfont XML built from the game's instruments, and the repository edits that register them.

## Layout

- `src/oot.h`: the converter, catalog and repository-patch interface used by the plugin and tests.
- `src/catalog_data.c`: instrument and drum catalog, generated by [`tools/oot_catalog.c`](../../tools/oot_catalog.c). It holds names, tuning data and soundfont XML attributes, and no sample audio.
- `src/catalog.c`: names, General MIDI defaults, instrument families and sample ranges.
- `src/sequence.c`: MIDI-to-sequence conversion and the soundfont XML.
- `src/repository.c`: sequence table, `spec`, audio cache and heap patches, and the install guide.
- `plugin/`: duckmidi settings, substitute review, colored-port layout and the export adapter.

The shared library builds as `plugins/OoT.dll` (`OoT.so`, `OoT.dylib`). The static target `ootexport_static` holds the converter without the plugin entry point, for tests.

## Regenerate the catalog

The catalog comes from a decomp's audio extraction. From the repository root, with GCC on PATH:

```sh
gcc -std=c17 -O2 -o build/development/oot_catalog tools/oot_catalog.c
build/development/oot_catalog <oot>/extracted/ntsc-1.0/assets/audio libraries/ootexport/src/catalog_data.c
```

Instrument names follow [LuigiXHero's OoT instrument list](https://github.com/LuigiXHero/OoT-Randomizer-Music-Pack/blob/master/OoT%20Instrument%20List%20and%20Custom%20Music%20Tips.md) and [TheSoundDefense's randomizer music guide](https://gist.github.com/TheSoundDefense/128c933b629e972835afb25692f9cc2d); edit the tables in `tools/oot_catalog.c` to rename instruments.

## Test

`oot_export_test` and `oot_install_test` run with the other tests (`ctest`). To check real output with a built decomp checkout, write the demo songs and build them with the decomp's own tools in its Linux environment:

```sh
build/development/cmake/bin/oot_export_test agents/reports/<run>
tools/validate-oot-export.sh <oot checkout> agents/reports/<run>
```

The script compiles the soundfont with `sfc`, assembles each sequence with `aseq.h` and the MIPS assembler, prints the assembled size beside duckmidi's prediction, and disassembles it again. It writes only into the given folder.

See the [OoT guide](../../docs/oot-export.md) for the export window and the [plugin API](../../docs/plugin-api.md) for the host contract.
